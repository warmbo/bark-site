Core modules

Everything Bark does, out of the box.

Nine modules, enabled and configured per server.

🛡 Moderation core

Cases, warnings, notes, bans, AutoMod, anti-raid and voice actions.

🏆 Reputation core

Engagement scoring, named tiers, rewards and leaderboards.

🎭 Role Manager core

Roles from joins, tenure, voice, Twitch status and reactions.

📣 Announcements core

Text or rich-embed announcements to a configured channel.

🔊 Auto Voice core

Temporary voice channels with naming, access and owner controls.

📜 Logging core

Message, file, member and voice-event history.

👋 Welcome core

Welcome and goodbye messages with optional rich embeds.

🗣 Speak core

Dashboard-configured phrases for quick, repeatable responses.

❓ Help core

Available commands and dashboard links delivered by DM.

Select a module for details, or sign in to configure one.
