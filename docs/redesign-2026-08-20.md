**Platform facts:**
- **Dashboard-first, one process**: discord.py bot + FastAPI/Jinja dashboard in a single async Python process; SQLite default via async SQLAlchemy; SSE live updates (`text/event-stream`).
- **Auth/permissions**: optional Discord OAuth2. Four ordered roles `viewer < moderator < admin < owner`. Per-server manage gating (owner / ADMINISTRATOR / MANAGE_GUILD / configured admin & moderator roles). View-only status page for non-grants. Page + API both enforced.
- **Plugins**: single-file `.py` modules installed from the dashboard (Modules → Plugins), no restart, per-server enablement (off by default), same `BarkModule` contract, owner-only install/remove. Repo `warmbo/bark-plugins`: fun, info, birthdays, giveaway, trivia, poll, profiles (media-engine), good_dog, minimal_example.
- **Self-hosted**: browser-based first-run setup wizard writes `.env`; health endpoint `/api/v1/health`; systemd unit example; reverse-proxy (incl. Cloudflare) support via `BARK_PUBLIC_URL` + `BARK_FORWARDED_ALLOW_IPS`; self-update manager (GitHub channel stable/dev, pre-update DB backup, no-downgrade guard).
- **Current real stats (2026-08-20, repo HEAD)**: version `0.3.332`, **783** collected tests, ~50k LOC Python, **9** core modules, **9** shipped plugins, 2 instances (prod `:8090` master, dev `:8091`).

## E. Design Rules (derived from Bark dashboard v0.3)

1. **Sharp, not rounded** — `border-radius: 0` on cards, buttons, badges, fields (matches `--radius: 0px`). No soft product rounding.
2. **Dark navy/near-black surfaces** — base `#0b0b0e`-ish; cards step up in navy (`#121216`). Thin crisp `1px` borders (`#1f1f23` / slate).
3. **Electric-blue accent** (`#3b82f6` family) for primary actions + active/focus; green (`#22c55e`) only for live/online status; semantic red for destructive; amber for notes/warnings.
4. **Typography** — Inter (self-hosted woff2) for UI, JetBrains Mono (self-hosted) for versions/IDs/commands. Semibold headings, tight tracking; `--muted-foreground` for secondary text.
5. **Density** — tight 4px/8px spacing scale; information over whitespace; muted secondary text keeps density readable.
6. **Status language** — pill tags (low-opacity accent bg + high-opacity text), green status dots, mono IDs — borrowed directly from the dashboard.
7. **Restrained motion** — honors `prefers-reduced-motion`; only where it aids comprehension (section reveals, hover states). No gradient SPA sheen.
8. **No CDN drift** — fonts local; no external JS frameworks; no decorative gradient overload. The wallpaper/avatar are first-party assets, used with restraint (not stacked with extra filters).
9. **Component vocabulary** — dashboard-inspired rows, module status rows, server-selector mock, permission hierarchy, activity timeline, plugin cards, install flow. Decoration never outnumbers information.
10. **Accessible** — visible `:focus-visible` ring, no color-only signaling, keyboard-navigable nav, semantic headings/alt text.

## F. Change Summary (implemented 2026-08-20)

The redesign was implemented as a static page (`index.html` + `assets/style.css` +
`assets/site.js`), replacing the previous 91-line site.

**What changed and why:**

- **Hero** — replaced "Bark is a good doggy" / "man's best friend" copy with a
  technically credible statement: **"Discord management from one dashboard."** Added a
  trust row (open source · self-hosted · MIT licensed · data stays yours), dual CTAs
  (Explore Bark / View on GitHub), and an authentic, live dashboard screenshot crop on
  the right. Removed the 1.9 MB autoplay hero video (heavy above-the-fold).
- **"What Bark Actually Does"** — new 6-card workflows section (Moderate / Manage
  Members / Build Reputation / Automate Roles / Automate the Server / Operate from the
  Web), each with verified capability lists instead of isolated buzzwords.
- **Dashboard showcase** — the dashboard is now the centerpiece. Real, current
  screenshots (v0.3.332) of Overview, Members, Moderation, Statistics and Modules with
  captions, replacing the stale v0.2.35 "Test Guild" preview. Added a Viewer →
  Moderator → Admin → Owner authorization band.
- **Modules** — 9 core module cards, each with a visible purpose statement; no hidden
  or expandable content.
- **Plugins** — new section: install-from-dashboard, no-restart, per-server enablement,
  same `BarkModule` contract; 8 real examples from `bark-plugins`; CTA to the repo.
- **Self-hosting** — expanded from one paragraph to four benefit cards (one service,
  data stays yours, simple deploy, easy backup).
- **Installation** — new "Running Bark" 4-step flow (Install → Open Setup → Connect
  Discord → Manage Server) with browser-first wizard mention; links to docs, not a
  homepage dump.
- **Security & permissions** — new section (OAuth, four role tiers, per-server authz,
  owner-controlled instance). No security theater.
- **Why Bark exists** — new "replace the pile of disconnected control panels" section
  with the one-dashboard / one-permission-model / one-workspace / one-history / one-
  deployment / one-visual-language message.
- **Navigation & CTAs** — richer nav (Product / Dashboard / Modules / Plugins /
  Self-hosting / Docs / Sign in), contextual CTAs throughout, strong final CTA.
- **Footer** — brand column + Product / Resources / Project link columns, MIT license,
  version.
- **Design** — derived from the Bark dashboard: sharp (`border-radius: 0`), dark
  navy/near-black, thin crisp borders, electric-blue accent, green status dots,
  mono-font version/IDs, dense but readable, restrained wallpaper backdrop, reduced-
  motion aware. Self-hosted Inter + JetBrains Mono fonts (no Google Fonts CDN).
- **Performance** — self-hosted fonts, screenshots converted to WebP (37–81 KB each),
  lazy-loaded below-the-fold images, hero screenshot eager + `fetchpriority=high`, no
  JS framework (progressive enhancement only).
- **Responsive** — verified clean at 320/390/768/920/1080/1280/1600 px; nav collapses
  to a hamburger below 920 px; grids collapse gracefully; no horizontal overflow.
- **SEO/share** — complete `<title>`, meta description, canonical URL, OpenGraph and
  Twitter cards (with image dimensions), theme-color, one `<h1>`, descriptive alt text,
  semantic headings.

**Removed:** stale hardcoded stats (LOC, source files, test count), hero video, old
"Test Guild" preview, Google Fonts CDN.
